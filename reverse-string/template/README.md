# String Reversal Web App

A simple web application that reverses any input text string. Built with vanilla JavaScript, this project demonstrates basic DOM manipulation and string operations.

## Features

- Instant string reversal
- Copy to clipboard functionality
- Modern, responsive UI
- Error handling for clipboard operations

## Demo

Input the text "AI4Devs" and get "sveD4IA" as output.

## Setup

This is a static web application that requires no build process or dependencies for running. Simply:

1. Clone the repository
2. Open `index.html` in your web browser

## Development

If you want to run the tests, you'll need Node.js and npm installed. Then:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run tests:
   ```bash
   npm test
   ```
